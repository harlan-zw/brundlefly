# Brundlefly

Self-contained Agent Skills collection with a shared body horror mascot.
Skills are Markdown instructions. There is no runtime build step.

## Read first

- Read [GLOSSARY.md](GLOSSARY.md) before naming a skill or product concept.
- Read [VISION.md](VISION.md) before changing scope or adding claims.
- Read [CONTRIBUTING.md](CONTRIBUTING.md) before adding a skill.
- Read [brand rules](docs/arch/brand.md) before changing visual assets.
- Read [repository conventions](docs/arch/conventions.md) before changing structure.
- Read [quality comparisons](docs/ideas/skill-quality.md) before proposing evaluations or competitor claims.

## Skill boundaries

Every skill must work when its directory is copied alone.
Keep required references, scripts, templates, and licenses inside that directory.
Use relative paths for bundled files.
Do not depend on another skill from a personal collection.
Do not require a private account or personal checkout.

Use the standard name and description frontmatter fields.
The name must match the containing directory.
Describe the task and its trigger in plain words.
Keep the main instructions short and move detailed material into references when useful.

## Branding

The corrected full-arm banner is the canonical banner.
Use assets/brand for current artwork.
Use assets/source for high-resolution masters.
Use assets/archive only for historical design reference.
Preserve the four arms, two legs, and two wings.
Confirm additional public slogans and decorative text with the owner.
