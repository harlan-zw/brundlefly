## Authority

The root GLOSSARY.md owns product names. VISION.md owns claims.
The root README.md and docs/arch/brand.md supply the existing collection voice.
This file points to those sources. It does not supersede them.
The website adds functional demo labels within the requested site scope.
Use the canonical banner. The owner authorized the Luna mascot dialogue and its proposed voice.
Do not add a promotional slogan.

## Register

| Surface | Rule | Example |
| --- | --- | --- |
| Navigation | Name the destination | Skills, Demos, Use a skill, GitHub |
| Buttons | State the action | Review text, Build an outline, Format a PR, Copy command |
| Inputs | Name the supplied fact | Your text, Reader’s task, Intended reader, Change, Reason |
| Empty | State the next action | Add some text first. |
| Success | Report the result | Copied. |
| Error | Give a useful next action | Keep the title under 70 characters. |
| Demo limits | State the actual behavior | Wording signals invite review. They do not identify an author. |
| Writing output | Preserve input and suggest review | Consider “use” if it preserves the meaning. |
| Guide output | Distinguish structure from research | This demo builds a structure. The full skill researches and verifies the guide. |
| PR output | Distinguish formatting from submission | This demo formats a draft. The full skill follows the target repository’s rules. |

## Banned language

| Avoid | Reason |
| --- | --- |
| Authorship scores or detection claims | Word patterns cannot establish authorship. |
| Claims of checks passing | Formatting a draft does not run checks. |
| Invented testimonials or usage figures | The collection has no evidence for them. |
| New promotional slogans | The owner controls promotional text. |
